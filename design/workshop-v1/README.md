# 작업실 첫 장면 시안 v1

상태: 콘셉트 확정(2026-10-31, 기록장·카드 덱 대안과 비교 후 선택). 이 파일은 회색 시안이며 운영 사이트 수정·커밋·배포는 없다. 그림은 최종본이 아니다.

방문자: 채용 담당자, 스레드에서 넘어온 사람, 서비스에서 역추적해 온 사람. 공통 질문은 "이 사람은 누구고 무엇을 만들었나"이다.

## 말 없이 전달할 행동

| 물건 | 무엇 | 누르면 바뀌는 상태 (방에 남음) |
| --- | --- | --- |
| 사람 | 이건하 | 뒤돌아보고 손을 든다 |
| 책상 위 종이 | L-Proof AI | 맨 위 장이 들리고, 공개 API의 최신 호 번호·제목이 적혀 있다 |
| 밥공기 | How Much Calories Left | 한 공기가 반 공기로 줄어든다 |
| 오락기 | 메이플랜드 레범몬 | 꺼진 화면이 켜지고 몬스터가 움직인다 |
| 은빛 책 | 은빛 서약 | 선반에서 앞으로 빠져나온다 |
| 메모판 | HIS | 흩어진 메모가 정렬되고 새 메모가 붙는다 |
| 서랍장 | 실무 경험 | 서랍이 열리고 파일이 드러난다 |

방은 서울 시각으로 낮·저녁·밤이 바뀌고, 벽시계도 서울 시각을 가리킨다. `?ref=l-proof`, `?ref=l-proof-about`, `?ref=calories`, `?ref=rebemon`으로 들어오면 해당 물건 앞에서 시작한다.

## 실행

저장소 루트에서:

```powershell
python -m http.server 8770 --bind 127.0.0.1 --directory design
```

http://127.0.0.1:8770/workshop-v1/

`?t=day`, `?t=dusk`, `?t=night`로 시간을 고정할 수 있다. 오른쪽 위 조작부는 검토용이며 운영에는 넣지 않는다.

## 이번 시안이 답하려는 질문

1. 글을 읽기 전에 사람과 작업실로 보이는가.
2. 물건을 눌러 보고 싶어지는가, 빨간 점이 필요한가.
3. 상태 변화가 제품을 떠올리게 하는가, 설명을 읽어야 아는가.
4. 다 눌러 본 뒤 달라진 방에서 "살아 있다"는 느낌이 드는가.

## 운영으로 옮길 때의 메모

- L-Proof 데이터는 브라우저 fetch 대신 서버에서 읽는다.
- 카메라는 viewBox를 매 프레임 바꾼다. 최종 그림의 복잡도에서 저사양 기기 성능을 다시 재야 한다.
- 터치 영역은 방 전체 위의 별도 레이어에 둔다. 물건 안에 두면 앞쪽 가구가 터치를 가로챈다.
- 경력을 빠르게 훑는 구역과 스레드 링크는 아직 없다.
