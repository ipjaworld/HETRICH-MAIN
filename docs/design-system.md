# HETRICH 디자인 시스템 · 1차

- 서체: 본문·제목과 영문에 IBM Plex Sans KR, 짧은 분류 라벨에 DM Mono. 400은 본문, 500은 제목, 600은 제품명과 주요 버튼, 700은 기존 강조 용도로만 사용한다. 시스템 폰트는 로딩 실패 시 대체용이다.
- 글자: 본문 16px/1.8, 섹션 제목 28–41px/1.35, 히어로 32–64px/1.35 (모바일 별도 축소). 제목 자간 -0.035em. 긴 한국어는 강한 굵기보다 행간과 여백으로 구분한다.
- 색: 따뜻한 배경 #f8f7f3, 본문 #242923, 보조 #646861, 강조 #3e55a5, 구분선은 잉크 14% 불투명도. 상태 색상은 제품 문맥별로 유지한다.
- 공간: 기본 단위 8·16·24·32·48px, 섹션 64–112px, 최대 폭 1280px, 좌우 20–72px. 제품은 데스크톱 2열, 모바일 1열.
- 표면: 이미지 12px, 사례 패널 20px, 버튼은 완전 둥근 형태. 구분선은 얇게, 그림자는 제품 캡처에만 사용한다.
- 상태: 주요 버튼은 어두운 바탕, hover는 파란색, 키보드 focus는 3px 파란 테두리, disabled는 흐리게 표시한다. 링크는 밑줄·화살표로 행동을 알린다.
- 모션: UI 반응 200ms, 이미지 350ms, ease. 스크롤 선은 장식이며 reduced motion에서는 움직임을 제거하고 내용을 유지한다.
- About의 네 원칙 문구는 사용자 피드백을 받은 기존 문구다. 대체 문단은 아직 승인되지 않아 이번 변경은 글꼴·레이아웃에만 적용한다.
