# HETRICH 디자인 시스템 · 1차

- 서체: 본문·제목과 영문에 IBM Plex Sans KR, 짧은 분류 라벨에 DM Mono. 400은 본문, 600은 의미상 제목, 500은 버튼과 링크에 사용한다. 700은 기존 강조 용도로만 사용한다. 시스템 폰트는 로딩 실패 시 대체용이다.
- 글자: 본문 16px/1.65, 섹션 제목 28–41px/1.3, 히어로 32–64px/1.3 (모바일 제목 행간 1.35), 라벨과 버튼 행간 1.4. 제목 자간 -0.035em. 글줄은 응집하고 문단·제목·카드 그룹 사이 여백으로 구분한다.
- 색: 따뜻한 배경 #f8f7f3, 본문 #242923, 보조 #646861, 강조 #3e55a5, 구분선은 잉크 14% 불투명도. 상태 색상은 제품 문맥별로 유지한다.
- 공간: 기본 단위 8·16·24·32·56px, 섹션 72–120px, 최대 폭 1280px, 좌우 20–72px. 제품은 데스크톱 2열, 모바일 1열.
- 표면: 이미지 12px, 사례 패널 20px, 버튼은 완전 둥근 형태. 구분선은 얇게, 그림자는 제품 캡처에만 사용한다.
- 상태: 주요 버튼은 어두운 바탕, hover는 파란색, 키보드 focus는 3px 파란 테두리, disabled는 흐리게 표시한다. 링크는 밑줄·화살표로 행동을 알린다.
- 모션: UI 반응 200ms, 이미지 350ms, ease. 스크롤 선은 장식이며 reduced motion에서는 움직임을 제거하고 내용을 유지한다.
- About의 네 원칙 문구는 사용자 피드백을 받은 기존 문구다. 대체 문단은 아직 승인되지 않아 이번 변경은 글꼴·레이아웃에만 적용한다.

버튼은 단일 링크 또는 button 요소를 사용한다. 최소 높이 48px, 좌우 28px·상하 12.8px 여백과 1.4 행간을 기준으로, 긴 문구는 내용에 따라 높이가 늘어난다. 아이콘은 별도의 클릭 요소가 아닌 장식이며 flex 중앙 정렬한다.

버튼의 라벨과 아이콘은 하나의 inline-flex 그룹으로 묶고 동일한 글꼴 행간에서 정렬하고 그룹 전체를 1px 아래로 시각 보정한다. 바깥 링크나 버튼은 패딩·최소 높이·상호작용을 담당한다.

내부 페이지도 같은 제목·본문·라벨과 버튼 토큰을 사용한다. Work는 사례 단위와 참여 맥락을 구분선으로, Products는 제품별 표면 색과 실제 화면을, Insights는 발행물 카드와 오류·빈 상태를 유지한다. Contact의 필드와 대체 안내는 공통 표면·focus·오류 상태를 사용한다.
