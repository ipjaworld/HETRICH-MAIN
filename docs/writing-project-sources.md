## 공개 문구와 근거

- 출발 동기: exp-000, exp-001의 제한된 시간·비용 안에서 실제 개발 업무를 수행하려던 경험.
- 다른 사람이 자기 환경에서 시도할 출발점을 남기려는 방향: exp-000의 독자 목표와 DIRECTION.md에 기록된 저자의 직접 문제의식. 방향 문서의 AI 제안 문장을 저자 직접 인용으로 표시하지 않음.
- ‘한 페이지’의 작업 범위를 오판하고 요구사항을 재정의한 사례: exp-005의 저자 직접 서술과 저자 승인된 ‘검증 가능한 단위’ 해석.
- 최초 산출물과 완료의 차이: exp-007의 저자 경험. 구현 시간·완성도·작업량 수치는 기억 및 대응 관계가 미확인되어 웹사이트에 싣지 않음.
- 혼자 해결하려는 확신이 협업을 늦춘 경험: exp-007의 저자 발화와 2026-09-15 편집 방향. 본인이 처음부터 책임 재배치를 선도했다고 재구성하지 않음.
- 현재 상태: 저장소에서 경험 기록 8개(출발점 포함), 챕터 초고는 없음. 2026-10-23 사용자 설명에 따라 ‘다른 우선순위로 집필을 미뤄둔 상태’ 표시. 기존 계획 일정을 현재 실적으로 쓰지 않음.
- 제목 ‘짠내나는 AI 개발 방법론’은 BOOK.md의 가제. 출간·판매·강의 제공을 암시하지 않음.

## 공개 범위

홈에는 공개 제품과 별도로 Working notes / Writing project 섹션을 추가. About에는 제품을 만들며 얻은 판단 기준도 공유하고 싶다는 방향과 홈 섹션 링크를 추가.

원본 경험·원고는 변경하지 않음. 회사·서비스·업종·프로젝트명, 경로·API·금액·정책·결함의 재현 정보는 제외. 익명화 문서에 맞춰 개인의 판단과 배움만 요약함. 완성된 방법론·검증된 교육 효과·출간 일정으로 소개하지 않음.

이번 홈페이지 글은 집필 원고나 승인된 챕터 발췌가 아닌 별도의 소개 문구다. 제품은 반복되는 수고를 줄이고, 경험 기록은 시작할 때의 막막함을 줄이려는 방향으로 연결한다.
