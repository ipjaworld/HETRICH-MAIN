# Studio artwork — 다음 사람이 시작할 수 있는 자리

홈의 방향성 소개와 집필 경험 사이에 배치한 상징적 일러스트입니다. 실제 인물 사진이나 제품 화면이 아닙니다.

- 제작: 2026-10-23, 사용자 요청에 따라 imagegen으로 생성.
- 주제: 직접 만들고 고친 경험이 다음 사람의 출발점이 되는 스튜디오.
- 접고 다시 만든 종이 모형은 시행착오, 미완성 다리는 계속 만드는 과정, 푸른 표식과 갈림길은 다음 사람을 위한 도움과 남겨둔 선택을 표현합니다.
- 기존 사이트의 종이색·푸른색·세이지색과 맞춘 종이 공예 질감입니다.
- 웹 자산: `public/images/studio-pathways.webp`, 1536 × 1024, 155,588 bytes. 원본 비율을 유지하며 모바일에서도 그림을 자르지 않습니다.
- 구현: 서버 컴포넌트의 Next Image, 명시적 크기와 반응형 sizes, 설명형 대체 텍스트. 추가 클라이언트 스크립트나 애니메이션은 없습니다.

홈 흐름은 핵심 문장 → 아트웍 → 경험과 집필 상태 → 출시 제품과 실무 경험입니다. 첫 화면의 제품 탐색·협업 링크는 유지합니다.
